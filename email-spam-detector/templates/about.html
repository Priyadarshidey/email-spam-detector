About the project

An AI-powered Email Security Analyzer built as a college Project-Based Learning (PBL) assignment.

Project objective

To build a web application that uses machine learning to classify emails as spam or not spam, and to explain every result clearly enough that a non-expert can understand why an email looks risky.

Problem being solved

Spam and phishing emails waste time and trick people into sharing passwords, money or personal details. A plain “spam / not spam” label is hard to trust, so this project adds a risk score, highlighted evidence, link checks and a downloadable report.

Machine learning approach

Text is converted to TF-IDF features (words and word pairs) and classified by a Multinomial Naive Bayes model trained on labelled spam / not-spam messages. See How It Works for details and evaluation results.

Key features

  • Real-time email statistics and sample emails
  • Spam probability, confidence and a 0–100 risk meter
  • “Why this result?” explanations and keyword highlighting
  • URL analysis, .txt / .eml upload, PDF report
  • Dashboard, searchable history, dark / light mode
