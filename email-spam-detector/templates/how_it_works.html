What the model does

The model reads an email and estimates the probability that it is spam (unwanted, deceptive or bulk messages such as scams, fake prizes and phishing) versus not spam (a legitimate message). The class with the higher probability becomes the prediction.

The algorithm is Multinomial Naive Bayes from scikit-learn, a classic, fast text classifier that learns which words are more common in spam than in legitimate messages.

What data it uses

The model is trained on spam.csv, a labelled dataset of messages marked spam or ham (not spam). {% if metrics %}It currently contains {{ metrics.dataset.total }} messages ({{ metrics.dataset.spam }} spam, {{ metrics.dataset.ham }} not spam), which gives the model a vocabulary of {{ metrics.dataset.vocabulary }} terms.{% endif %}

This is a small demonstration dataset. Words the model has not seen are ignored, so a larger dataset would make predictions much more reliable. Replace spam.csv and run python train_model.py to retrain.

How preprocessing & features work

  • Text is converted to lower case and split into words.
  • Common English stop words (“the”, “and”, “is”…) are removed.
  • Single words and two-word phrases (bigrams) are counted, up to 5,000 features.
  • TF-IDF weights each term: frequent in this email but rare across the dataset means more important.

How prediction works

For each class, Naive Bayes adds the class’s prior probability to the weighted log-likelihood of every term in the email, then converts the two scores into probabilities that sum to 100%.

score(class) = log P(class) + Σ tfidf(term) · log P(term | class)

The risk score is simply P(spam) × 100, rounded. Bands: 0–30 Safe, 31–60 Suspicious, 61–100 High risk.

Model vs. rule-based analysis

PartWhere it comes fromUsed for
ML modelTrained TF-IDF + Naive Bayes modelVerdict, spam probability, confidence, risk score, “words that influenced the model”
Rule-basedKeyword lists and link checks written in services/heuristics.pyHighlighted keywords, URL assessments, detected indicators
HeuristicSimple 0–100 formulas over the rule-based findingsThe spam risk breakdown bars

Rule-based results never change the model’s prediction. They exist to help a person understand an email. URL checks are not confirmed verdicts: links are never visited or looked up in a blocklist. “Confidence” is the probability of the predicted class (High ≥ 80%, Medium 60–79%, Low < 60%).
